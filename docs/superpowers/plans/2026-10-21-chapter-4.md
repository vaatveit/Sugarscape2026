## Review Focus

1. **Degenerate preferences.** With cultural preferences an agent can have f = 0 or 1 (all tags one value), giving an MRS of 0 or ∞; a zero holding does the same. No division error, no NaN price, no trade. Test in Task 4.
2. **Trade invariants.** Over random runs: sugar and spice totals conserved by trade, both traders' welfare strictly rises with every exchange, MRS order never crosses, no holding goes ≤ 0 through trade. Test in Task 4.
3. **Periods with no trades.** `mean_price`, `mean_log_price`, `price_sd` are `nan` (not errors) when nobody trades; `price_sd` is 0.0 with a single trade. Test in Task 6.
4. **Death by spice.** An agent whose spice reaches ≤ 0 dies even with plenty of sugar; inheritance and replacement carry spice. Tests in Tasks 2 and 3.
5. **Loans and deaths.** No sugar moves to or from a dead agent; a dead borrower's loans vanish; a dead lender's loans vanish or pass to living children under I; a broke borrower pays half and the remainder is re-lent. Test in Task 5.

```python
@dataclass
class Loan:
    lender: Agent; borrower: Agent
    principal: float; due: float; due_t: int
def available_to_lend(model, agent) -> float     # too old: sugar / 2; fertile with surplus: sugar - initial_sugar; else 0
def shortfall(model, agent) -> float             # fertile-age borrower: initial_sugar - sugar if positive, else 0
def creditworthy(model, borrower, amount_due: float) -> bool
def seek_credit(model, agent) -> list[Loan]      # borrower asks neighbors in random order until covered
def settle_loans(model) -> None                  # loans with due_t == model.t: repay, or pay half + re-lend remainder
def on_death(model, agent) -> None               # drop loans; pass lender's loans to living children under I
```

"Too old" means `age >= fertility_end`; "childbearing age" means `fertility_start <= age < fertility_end`. `d, r = Config.credit`; `due = principal * (1 + r / 100 * d)`; `due_t = t + d`.
