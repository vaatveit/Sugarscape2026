## Review Focus

1. **The mover counted as its own neighbor (Schelling).** A candidate site next to the agent's current site must be judged without the agent itself. Otherwise a red agent looking one step away counts itself as a like neighbor. Test in Task 2.
2. **No acceptable site anywhere, or no neighbors at all (Schelling).** A dissatisfied agent with nowhere acceptable to go stays put, with no crash or endless loop. An agent with no neighbors is satisfied (0/0). Tests in Task 2.
3. **The seam of the ring.** The search wraps from 149 to 0. A group straddling site 0 counts once, and a ring where every gap is small is a single group. Tests in Task 3.
4. **A full field of view (Ring World).** The back of a megagroup whose vision covers only occupied sites has no candidate and stays (p.175); it must not jump past its vision. Test in Task 3.
5. **Credit plus spice plus disease together.** Sugar loans leave spice untouched. A lender or borrower who dies of spice or disease clears its loans. A 40-period all-rules run keeps one agent per site and only living parties to loans. Tests in Task 1.

| Schelling agents | Color by a fair coin. Preference is a uniform real in `preference`. Age starts at 0 and rises by 1 at the end of each period. | Segregation measure | `like_fraction` is the mean like share over agents with at least one neighbor (≈0.5 for a random board). The book shows only pictures. | our call |
| Ring World | 150 sites; integer sugar U{0..4} (integer levels our call); capacity 4; unit growback after all agents move. 40 agents with vision U{15..30}. Counterclockwise means increasing index. | p.172 |
| Ring move | Look at the unoccupied sites at distances 1..vision ahead and go to the one with the most sugar, the nearest on ties. If none is visible, stay. Eat the sugar on the site where the agent ends up. | p.172, p.175 |
| VI-9 start | One contiguous block of 40 agents starting at a random site. | p.174 |
| Ring groups | A group is a maximal run of agents with at most one empty site between consecutive members (`gap=1`; random call order opens small gaps, fn 13). | our call |
| Comparative claims | `Target.baseline`: the per-seed value is this experiment's statistic divided by the same statistic on the baseline experiment's seed of the same index. | p.159, p.166, p.170 |

@dataclass(frozen=True)
class SchellingConfig:
    width: int = 50                                  # p.166: 50x50 torus
    height: int = 50
    population: int = 2000                           # p.166: 20% of sites vacant
    preference: tuple[float, float] = (0.25, 0.25)   # uniform range of minimum like shares (p.166, p.170)
    max_age: tuple[int, int] | None = None           # None: infinite lifetimes (VI-4); (80, 100) for VI-5..VI-7
    seed: int = 0
    # ValueError: population < 0 or > width*height; preference not 0 <= lo <= hi <= 1; max_age lo < 1 or lo > hi

@dataclass(eq=False)
class Resident:
    x: int
    y: int
    color: str              # "red" | "blue"
    preference: float
    max_age: float          # math.inf without lifetimes
    age: int = 0
    moved: bool = False     # moved this period

class SchellingModel:
    config: SchellingConfig; rng: np.random.Generator; agents: list[Resident]; t: int
    replaced_this_step: int
    def __init__(self, config: SchellingConfig) -> None       # places `population` random agents at distinct sites
    def place(self, x: int, y: int, color: str, preference: float, max_age: float = math.inf) -> Resident
    def agent_at(self, x: int, y: int) -> Resident | None
    def like_share(self, agent: Resident, x: int, y: int) -> float | None   # None: no neighbors (agent itself excluded)
    def satisfied(self, agent: Resident, x: int | None = None, y: int | None = None) -> bool  # default: its own site
    def acceptable_sites(self, agent: Resident) -> list[tuple[int, int]]   # empty sites where it would be satisfied
    def step(self) -> None
    def run(self, steps: int, observer: Callable[["SchellingModel"], None] | None = None) -> None  # same contract as Model.run

def schelling_metrics(model: SchellingModel) -> dict[str, float]
    # population, n_red, like_fraction (mean like share over agents with >= 1 neighbor; nan if none),
    # fraction_satisfied (nan if empty), moved (agents that moved this period), replaced (this period); plain floats
```

`step` follows the Decisions table: a shuffled turn for every agent, then aging, removal, and same-period replacement.

@dataclass(frozen=True)
class RingConfig:
    sites: int = 150                         # p.172
    capacity: int = 4                        # p.172
    initial_sugar: tuple[int, int] = (0, 4)  # uniform integers (p.172; integer levels our call)
    population: int = 40                     # p.172
    vision: tuple[int, int] = (15, 30)       # p.172
    placement: str = "random"                # "random" (VI-8) | "block": one contiguous group (VI-9, p.174)
    growback_rate: float = 1.0               # "unit rate" (p.172)
    seed: int = 0
    # ValueError: population < 0 or > sites; vision lo < 1, lo > hi, or hi >= sites;
    # initial_sugar not 0 <= lo <= hi <= capacity; unknown placement

@dataclass(eq=False)
class Harvester:
    position: int
    vision: int
    advanced: int = 0        # sites moved counterclockwise this period

class RingModel:
    config: RingConfig; rng: np.random.Generator; sugar: np.ndarray; agents: list[Harvester]; t: int
    def __init__(self, config: RingConfig) -> None
    def place(self, position: int, vision: int) -> Harvester
    def agent_at(self, position: int) -> Harvester | None
    def choose_site(self, agent: Harvester) -> int | None   # None: every site in view is occupied
    def step(self) -> None
    def run(self, steps: int, observer=None) -> None

def groups(model: RingModel, gap: int = 1) -> list[list[Harvester]]
    # maximal runs around the ring with at most `gap` empty sites between consecutive agents;
    # singletons are runs of one; one run when no gap anywhere exceeds `gap`
def ring_metrics(model: RingModel, gap: int = 1) -> dict[str, float]
    # n_groups (runs of >= 2), largest_group (0 if empty), mean_group_size (population / runs, singletons included),
    # group_size_cv (std/mean over runs of >= 2; nan if fewer than 2), clustered_fraction (agents in runs of >= 2),
    # within_vision_bound (share of runs of >= 2 whose size <= their smallest vision; nan if none),
    # speed_grouped, speed_alone (mean `advanced`; nan if no such agents),
    # speed_ratio (grouped / alone; nan if either is nan or alone == 0)
```

`step`: reset `advanced`; agents act in a fresh random order. Each one moves to `choose_site`, or stays if that is `None`, records `advanced`, and sets the sugar of its final site to 0. Then every site regrows by `growback_rate` up to `capacity`, and `t += 1`.
