# Sugarscape xxl Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The xxl rule set in the Julia port: six switchable rule changes on the 500 × 500 world, combat under
them, a `--xxl` runner flag, the `XXL-…` experiments, their metrics, a report and the `docs/xxl.md` contract.

**Architecture:** One immutable `XxlRules` struct hangs off Julia's `Config` as its one Julia-only field. Every hook
point checks its own feature and takes the existing code path when that feature is at its book setting, so an xxl
run at book settings is byte-for-byte the Julia xl run; that reduction test guards every task from Task 3 on. New
code lives in new files under `julia/src/xxl/`; book rule files gain only the dispatch lines.

**Tech Stack:** Julia 1.13, standard library only (`Random`, `SHA`, `TOML`, `Distributed`; add nothing to
`[deps]`). Formatting: `julia --project=julia/tools julia/tools/format.jl` (BlueStyle).

**Spec:** [docs/superpowers/specs/2026-10-28-xxl-design.md](../specs/2026-10-28-xxl-design.md)

## Global Constraints

- Julia only. Nothing under `sugarscape/`, `experiments/`, `viewer/`, `tests/` or `julia/bridge/` changes, except
  the two new map files in `sugarscape/maps/` (Task 10; `.gitattributes` already covers them). The one other change
  outside `julia/` is `results-julia-xxl/` in `.gitignore` (Task 12). `julia/registry.toml` is not regenerated or
  edited.
- **Include order in `Sugarscape.jl`:**
  - `xxl/types.jl` (`XxlRules`, `XXL_BOOK`, `XXL_DEFAULTS`, `Remembered`) before `config.jl`;
  - `xxl/transform.jl` (`to_xxl`, `xxl_on`) after `xl.jl`;
  - `xxl/terrain.jl` after `maps.jl`;
  - `xxl/geometry.jl` after `model.jl`;
  - `xxl/vision.jl`, `speed.jl`, `memory.jl`, `combat.jl` and `radius.jl` after `rules/disease.jl`;
  - `xxl/metrics.jl` after `stats.jl`;
  - `xxl/experiments.jl` after `runner.jl`.

  Functions typed on `Model` never go in a file loaded before `model.jl`.
- The remembered-site type is `Remembered`, not `Memory`, which would shadow `Base.Memory`.
- Every existing Julia test passes unchanged: `julia --project=julia -e "using Pkg; Pkg.test()"`, the scenarios,
  lockstep and hot-path tests included. The Python side's `pytest -q` in `julia/` passes unchanged.
- No existing test file is edited. New tests go in new files `julia/test/test_xxl_*.jl`, which `runtests.jl` picks
  up by name.
- With `cfg.xxl === nothing`, or a feature at its book setting, the existing code path runs and draws exactly what
  it drew before.
- Every xxl random draw is gated by its feature and comes after all existing draws of the same occasion (per agent:
  after the Chapter V draws; per period: inside the xxl hook).
- Rounding a real coordinate to a site is `round(Int, v)` (Julia's `RoundNearest`, ties to even), everywhere; the
  contract states it.
- Torus distance: `d = √(dx² + dy²)`, `dx = min(|Δx|, W − |Δx|)`, `dy` likewise.
- Book settings / `to_xxl` defaults, exactly:

  | Field | Book setting | Default |
  |---|---|---|
  | `vision_shape` | `"lattice"` | `"disc"` |
  | `speed` | `nothing` | `(1, 6)` |
  | `travel_cost` | `0.0` | `0.1` |
  | `memory` | `0` | `8` |
  | `memory_span` | `50` | `50` |
  | `word_of_mouth` | `false` | `true` |
  | `interaction_radius` | `1.0` | `1.5` |
  | `season_gradient` | `false` | `true` |
  | `landscape` | `"xl"` | `"xl"` |

## Review Focus

1. **The torus seam.** Disc samples, the step's straight-line walk and remembered targets across x = 0 / y = 0
   must take the short way round. Test: `test_xxl_speed.jl` "walk crosses the seam".
2. **An agent with nothing affordable.** When every candidate but its own site is dropped (would starve on the
   way), the agent stays and harvests its own site; nothing throws. Test: `test_xxl_speed.jl` "all candidates
   dropped".
3. **Newcomers.** Replacement agents (rule R) and children get a speed trait; founders too. Test:
   `test_xxl_speed.jl` "every agent has a speed".
4. **A remembered target that is occupied on arrival.** Within vision it is looked at afresh and excluded;
   nothing moves an agent onto an occupied site. Test: `test_xxl_memory.jl` "occupied remembered site".
5. **Tiny or empty populations.** The xxl metrics return `NaN`, never throw, with 0 or 1 agents and with no
   trades. Test: `test_xxl_metrics.jl` "empty and single".

**Files:**
- Create: `julia/src/xxl/speed.jl`

**Interfaces:**
- Produces:
  - `travel_periods(d, S) = S == 0 ? 1 : max(1, ceil(Int, d / S))`: without speed every site is reached in one
    period (and `validate` keeps c = 0 there)
  - `net_value(m, a, x, y, d, sugar, spice)::Float64`: the value of arriving at a site with these (devalued)
    resources, or `-Inf` if dropped. It implements the spec's h₁ / h₂ formula: b from `SiteWelfare`'s
    `base1`/`base2` with spice, `a.sugar` without; travel subtracted after the clamp, and welfare's own clamp at zero
    as now. The drop test uses the real holdings: `a.sugar − c·d − m₁(T−1) ≤ 0`, or `a.spice − m₂(T−1) ≤ 0` with
    spice. Own site (d = 0) is never dropped.
  - `step_site(m, a, tx, ty; ok=(x, y) -> true)::Tuple{Int,Int}`: pure, moves nothing. The target if `d ≤ S`
    and it is empty and `ok`. Otherwise the straight-line walk k = S … 1, taking the first site that is empty and
    `ok`; otherwise the agent's own site. It never returns an occupied site, including a remembered target that
    turns out occupied. `xxl_move!` moves to it with `move_agent!`.
  - `xxl_move!` gains the speed branch: candidates are the own site and the empty looked-at sites. The target is
    the highest net value, ties to the nearest, then at random (reservoir: on the c-th tie, replace with
    probability 1/c, one `rand(rng)` per tie). Then step, then `harvest!`.
