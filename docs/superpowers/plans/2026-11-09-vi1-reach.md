# VI-1 reach variants Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Three Julia-only variants of VI-1-distance in which combat and culture reach the same agents: `VI-1-near`
(combat at culture's reach), `VI-1-far` (culture at combat's sight) and `VI-1-far-speed` (culture at combat's attack
reach, today's xxl only).

**Architecture:** Two config values, `combat_reach` and `culture_reach`, default to today's behaviour so every existing
run is byte-identical. `combat_reach = "neighbours"` cuts the candidates and the fear check of both combat moves to the
culture neighbourhood, leaving the look (and xxl memory) as it is. `culture_reach = "sight" | "attack"` gives
`culture_transmit!` its own list of agents reached. The readings keep `culture_neighbors!`, which is already separate
from rule K.

**Tech Stack:** Julia, module `Sugarscape` in `julia/`, Test stdlib.

**Spec:** `docs/superpowers/specs/2026-11-09-vi1-reach-design.md`

## Global Constraints

- **Nothing that ran before changes.** With `combat_reach = "vision"` and `culture_reach = "neighbours"` (the defaults),
  III-9, III-11, III-12, III-13, III-14, VI-1, VI-1-combat and VI-1-distance give byte-identical CSV contents in the
  book's world, xl and today's xxl.
- **`Config.combat_reach::String = "vision"`**, one of `"vision"`, `"neighbours"`; `"neighbours"` needs combat
  (`combat_alpha !== nothing`).
- **`Config.culture_reach::String = "neighbours"`**, one of `"neighbours"`, `"sight"`, `"attack"`; anything but
  `"neighbours"` needs `culture`; `"attack"` needs xxl speed (`xxl_on(cfg, :speed)`).
- **The culture neighbourhood** is `culture_neighbors!`'s: the 4 von Neumann sites, or with xxl rule 4 the sites at
  `near_offsets(m, m.config.xxl.interaction_radius)` (1.5 in today's xxl).
- **VI-1-near, book's world and xl:** candidates are the own site and the 4 adjacent sites, in `random_directions`
  order, distance 1 only, whatever vision and `look_stride`; a site is vulnerable if a watcher on one of the 4 sites
  adjacent to it passes the fear test (wealth, then `hostile!`).
- **VI-1-near, xxl:** `look!` and `remember!` run as now (memory and word of mouth keep far sites); candidates are the own
  site and the looked-at sites within `interaction_radius`, each attackable and reached by a jump whatever the speed;
  remembered sites are not candidates; a site is vulnerable if an agent within `interaction_radius` of it passes the fear
  test.
- **VI-1-far:** rule K reaches the agents on the sites of combat's look from the agent's position, drawn afresh in rule
  K: book/xl the 4 lines in `random_directions` order, each `look_line!(…, look_stride, a.vision)`; xxl
  `look!(buf, m, a, a.x, a.y; memory=false)`. The agent itself excluded.
- **VI-1-far-speed:** rule K reaches the agents on `near_offsets(m, Float64(a.speed))` around the agent.
- **Rule K otherwise as now:** the reached list is shuffled with `m.rng`; each reached agent gets one random tag
  position copied from the agent's. Trade, credit, disease, mating, friends and the readings keep their neighbourhoods.
- **New scratch buffers** for rule K's look; never reuse `m.line`, `m.threat`, `m.looked` or `m.threat_looked`.
- **Experiments:** `VI-1-near` (= VI-1-distance + `combat_reach="neighbours"`), `VI-1-far` (+ `culture_reach="sight"`),
  `VI-1-far-speed` (+ `culture_reach="attack"`), each fingerprint VI-1-distance's plus one line:
  `variant: VI-1-near combat_reach=neighbours (attack, fear and movement within culture's reach)\n`,
  `variant: VI-1-far culture_reach=sight (culture reaches everyone combat sees)\n`,
  `variant: VI-1-far-speed culture_reach=attack (culture reaches everyone within speed)\n`.
  The combat study accepts all three; `VI-1-far-speed` only with `--world today` (`ArgumentError` otherwise).
- **No study run.** Suite runs and the Task 5 dry run (scratch folder) are fine.
- **Suite:** `julia --project=julia -e 'using Pkg; Pkg.test()'` (about 38 min). One file:
  `julia --project=julia -e 'using Pkg; Pkg.test(test_args=["<substring>"])'`.

## Review Focus

1. **xl's `look_stride` must not hide the adjacent sites in VI-1-near**: with `look_stride = 10`, an adjacent poorer
   hostile occupant is still a candidate. Test in Task 2.
2. **VI-1-near keeps xxl memory working**: after a move, the agent's memory can hold a site beyond 1.5 that it looked at.
   Test in Task 3.
3. **Rule K's reach excludes the agent itself and reaches each agent at most once** (the xxl look lists a site once; the
   4 lattice lines don't overlap). Test in Task 4.
4. **Rule K's new look doesn't disturb the combat move's buffers**: a move followed by `culture_transmit!` leaves
   `m.looked` as the move left it. Test in Task 4.
5. **VI-1-far-speed is refused outside today's xxl**, at config and at the study's command line. Tests in Tasks 1 and 5.
