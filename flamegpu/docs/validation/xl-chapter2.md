## Reading these results

  - **II-6 came from how contested sites were resolved.** On the GPU every agent picked from the round's start
    state, and a loser picked again after agents later in the order had taken the sites it would have reached first
    in Python's order.

      and the steady −4 to −6% after diffusion.
